# 天锋发布助手

![天锋](../品牌资源/天锋-banner.png)

天锋工作台的发布组件。工作台已直接连接本目录的适配器，不要求额外安装浏览器插件才能使用工作台。

如需在日常 Chrome 里独立使用插件：打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选择本目录。

插件把素材传入上传页并填写文案，最终发布由你确认。
